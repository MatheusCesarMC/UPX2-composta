# Composta+

Protótipo inicial desenvolvido para a UPX 2, relacionado à ODS 12.3 — redução do desperdício de alimentos.

A proposta é simular uma plataforma que conecta restaurantes à coleta de resíduos orgânicos destinados à compostagem.

## Tecnologias

- HTML
- CSS
- JavaScript

## Estado atual

Este é o primeiro protótipo do projeto. Ele possui uma página inicial com restaurantes fictícios, quantidades simuladas de resíduos e um botão para simular uma solicitação de coleta.
