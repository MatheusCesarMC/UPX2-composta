# 🌱 Composta+

## Sistema de Coleta e Destinação de Resíduos Orgânicos

O **Composta+** é um projeto acadêmico desenvolvido para a disciplina de **UPX 2**, relacionado ao **ODS 12 - Consumo e Produção Responsáveis**.

A proposta do projeto é apresentar, de forma simples, uma simulação de uma plataforma que conecta estabelecimentos geradores de resíduos orgânicos a um serviço de coleta e encaminhamento desses materiais para compostagem.

---

## 🎯 Objetivo

O objetivo do Composta+ é demonstrar como uma plataforma digital pode auxiliar na organização da coleta e destinação de resíduos orgânicos gerados por estabelecimentos.

O sistema busca apresentar um fluxo simples, desde o registro dos resíduos até a solicitação da coleta, acompanhamento da situação e encaminhamento do material para compostagem.

---

## ⚙️ Funcionalidades

O Composta+ permite:

- Cadastrar estabelecimentos;
- Informar a quantidade aproximada de resíduos orgânicos;
- Informar a frequência desejada para a coleta;
- Visualizar estabelecimentos participantes;
- Solicitar uma quantidade específica para coleta;
- Acompanhar o status da coleta;
- Atualizar a quantidade de resíduos disponíveis após uma coleta;
- Encaminhar os resíduos coletados para compostagem;
- Solicitar novas coletas quando ainda houver resíduos disponíveis;
- Visualizar indicadores simulados do projeto.

Os status das solicitações seguem o fluxo:

**Disponível para coleta → Coleta solicitada → Coletado → Em compostagem**

---

## 📊 Indicadores

A plataforma apresenta indicadores simulados para demonstrar os resultados do processo:

- Quantidade de estabelecimentos cadastrados;
- Quantidade total de resíduos registrados;
- Quantidade de resíduos encaminhados para compostagem.

Os indicadores são atualizados conforme as ações realizadas no protótipo.

---

## 🌱 Relação com o ODS 12

O projeto está relacionado ao **Objetivo de Desenvolvimento Sustentável 12 (ODS 12)**:

> **Consumo e Produção Responsáveis**

O Composta+ possui relação principalmente com as metas **12.3** e **12.5**, ao abordar a redução do desperdício de alimentos e o reaproveitamento de resíduos orgânicos por meio da compostagem.

A proposta também busca incentivar a conscientização sobre a destinação adequada dos resíduos e sobre a possibilidade de transformar materiais que seriam descartados em recursos reaproveitáveis.

---

## ♻️ Como funciona

O processo simulado pelo Composta+ pode ser resumido em quatro etapas:

**1. Resíduo orgânico**  
O estabelecimento registra a quantidade de resíduos disponíveis.

**2. Coleta**  
O usuário seleciona a quantidade que deseja coletar.

**3. Compostagem**  
Após a coleta, o material é encaminhado para compostagem.

**4. Reaproveitamento**  
O resíduo deixa de ser tratado apenas como descarte e passa a ter potencial de reaproveitamento.

---

## 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias básicas de desenvolvimento web:

- HTML5
- CSS3
- JavaScript

O protótipo utiliza **LocalStorage** para armazenar os estabelecimentos cadastrados e o andamento das coletas.

Não são utilizados banco de dados ou frameworks externos.

---

## 🧪 Funcionamento do protótipo

O projeto é uma **simulação desenvolvida para fins acadêmicos**.

Os estabelecimentos, quantidades de resíduos e solicitações apresentadas no sistema são utilizados para demonstrar o funcionamento da proposta.

A quantidade coletada pode ser definida pelo usuário, desde que não ultrapasse a quantidade disponível no estabelecimento.

---

## ⚠️ Observação

O Composta+ é um **protótipo acadêmico** e não representa um serviço real de coleta ou compostagem.

Os dados apresentados são simulados e têm como finalidade demonstrar o funcionamento e a proposta do projeto.
